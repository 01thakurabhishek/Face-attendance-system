# Face Recognition Attendance System

The Face Recognition Attendance System is a web-based college management application designed to simplify attendance tracking and academic record management. The primary goal of this project is to reduce manual paperwork, save teachers' time, improve record organization, and make college administration more efficient.

The application integrates face recognition technology with a database-driven web platform to support student identification and attendance management. It also provides modules for managing student profiles, teacher information, lectures, examinations, notes, marks, and attendance records.

## Key Features

- **Face Recognition:** Integrates face-recognition models to support student identification.
- **Attendance Management:** Helps maintain and monitor student attendance records.
- **Student Management:** Organizes student profiles and related information.
- **Teacher Management:** Maintains teacher details and academic records.
- **Lecture Management:** Supports organizing lecture-related information.
- **Examination Management:** Provides modules related to exams, questions, marks, and submissions.
- **Notes Management:** Helps organize educational notes and learning resources.
- **Database Integration:** Uses MySQL to store structured college information.
- **Academic Records:** Supports efficient access to student and attendance information.

## Technologies Used

The project uses React, TypeScript, and Vite for the frontend interface. Node.js and Express.js handle backend operations and API requests. MySQL provides database storage, while `@vladmandic/face-api` supports face-detection and recognition functionality.

## Installation and Setup

First, clone or download the repository and install the required dependencies for the frontend and backend. Configure the MySQL database using the provided SQL schema, then update the database credentials in the backend environment configuration. Start the backend server and frontend development server according to the project instructions. Finally, open the application in your browser to explore its available features.
